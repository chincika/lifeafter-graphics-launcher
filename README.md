# 明日之后画质启动器

这是“明日之后画质启动器”的官方发布仓库。
## 下载

请仅从本仓库的 [Releases](https://github.com/chincika/lifeafter-graphics-launcher/releases/latest) 页面下载最新版：

- Windows 10/11 x64 便携版
- 文件名格式：`LifeAfter-Graphics-Launcher-<版本>.exe`
- 同一 Release 中提供 SHA-256 校验清单

## v2.3.4 更新器修正版

v2.3.4 修复旧便携版退出时连带终止更新工作进程的问题。更新工作进程现在由 Windows Shell 独立拉起，同时保留下载复用、文件占用重试、失败回滚和缓存清理。

> v2.3.5 是用于验证 v2.3.4 自动替换链路的测试版。为使启动器能够通过 `/releases/latest` 检测到它，GitHub 上按普通 Release 发布。

## 主要功能

- 老 PC 包体与发烧平台包体自动识别，也支持手动维护多个游戏目录
- 120 FPS 档可接管为 180 / 240 / 300 FPS，其余档位保持原配置逻辑
- 修改前完整事务备份、永久官方初始还原点、写后验证与失败回滚
- 性能启动模式、画质预设、多开与启动记录
- 最小化到托盘后低占用持续记录游戏时长
- 可选的局域网浏览器副屏，仅在本机保存记录和授权设备
- 启动检查更新并自动替换便携版，可调整检查频率

## 安全说明

- 自动更新会核对 GitHub Release 资产摘要，并以同一 Release 的 `SHA256SUMS.txt` 作为兼容校验来源。
- v2.3.1 已移除程序内的公钥、私钥签名验证与相关构建脚本。
- 启动器没有付费 Microsoft Authenticode 证书，Windows 可能显示“未知发布者”。请核对下载来源和 SHA-256。
- 应用或恢复帧率补丁前必须完全退出游戏。启动器只写入识别并验证通过的目标包体，并始终保留独立永久还原点。
- 混淆和完整性校验只能显著提高逆向与篡改成本，不能承诺客户端软件绝对无法被分析。

## 数据与隐私

启动记录、游戏目录列表、局域网授权设备和设置默认保存在每台电脑自己的应用数据目录中，不会打包进程序，也不会随 EXE 分享给他人。局域网副屏默认关闭，启用后只监听本地网络接口。
