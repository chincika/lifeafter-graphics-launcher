# 180 / 240 FPS 新版补丁说明

## 结论

补丁适配的是本机 2026-07-26 提取的当前 `script.py314.lc.npk`，不是旧版
WM 优化助手所使用的包体。

两份补丁均静态修改 `SettingManager.set_frame_rate`：

- 把相关的两个序列化指令字节从 `0x73` 改为 `0x44`；
- 把 `user_setting` 后的序列化占位对象 `0x78` 替换为
  `0xBE + uint32 little-endian`；
- 180 的整数编码为 `BE B4 00 00 00`；
- 240 的整数编码为 `BE F0 00 00 00`；
- 调试文件名元数据由 `SettingManager.py` 缩短为 `SettingMgr.py`，抵消新增的
  4 个序列化字节，使解压后模块仍为 328,632 字节。

执行路径仍是：

```text
frame_execute_mgr.request_frame_rate(固定整数)
game3d.set_frame_rate(固定整数)
```

它不是新增游戏原生 UI 档位，也不是 DLL 或进程内存注入。

## 固定槽位适配

当前目标记录压缩槽为 110,791 字节。常规 LZ4 HC 压缩后：

- 180 为 110,784 字节；
- 240 为 110,783 字节。

为了不改 NXPK 头和加密索引，补丁把一个已有 LZ4 匹配序列的前 7/8 个输出字节
改写为等价字面量。解压结果完全相同，但压缩流分别精确增加 7/8 字节，最终两份
补丁都严格等于原槽的 110,791 字节。

```text
官方原版 -> 180 FPS -> 240 FPS -> 恢复官方原版
```

每一步均识别到预期槽位哈希，槽外归一化整包校验通过；最终恢复后的完整 NPK
SHA-256 与原始值完全相同。

策略或实际渲染帧数。补丁不包含任何反作弊绕过。
